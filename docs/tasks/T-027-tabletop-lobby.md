## Контекст
В аудитории участники должны подключаться по QR из комнаты ожидания. Ведущий заполняет оставшиеся места случайными ботами одним действием. Визуальный стиль — современная настольная игра: бумага, карточки, монеты, бордовый и охра.

## Acceptance criteria
- [x] QR содержит действительную ссылку на конкретную игру, включая HashRouter/base path; есть крупный режим для проектора и копирование ссылки.
- [x] Новый участник открывает приглашение, вводит имя и присоединяется.
- [x] Ведущий одним действием заполняет свободные места смесью стратегий, не превышая вместимость; существующий выбор стратегии сохранён.
- [x] Новый стиль охватывает основные экраны; доступность клавиатурой, контраст и мобильная ширина сохранены.
- [x] Unit, lint, build, E2E и публичная проверка проходят; изменения опубликованы.

## Лог
- 2026-10-24: проверены компоненты приглашения/ботов и токены. QR генерируется локально библиотекой qrcode.react; случайное заполнение выполняется сервером под блокировкой сессии (T-109 backend). Данные и стек сохраняются.

- 2026-10-24: реализованы QR/режим проектора, атомарное случайное заполнение через T-109, бумажные карточки/монеты/бордовые кнопки и контрастный вторичный текст. Инструкция ведущего обновлена.
- Проверки: 87 Vitest, lint, TypeScript/build; 24 Playwright без retries на изолированной PostgreSQL. Новый QR декодируется независимым jsQR, приглашение проходит регистрацию и join; Escape возвращает фокус, гость не видит управления ботами. После исправления порядка WebSocket отдельный сценарий повторён успешно.
- Первый E2E был запущен до готовности тестового API и завершился ошибками health-check; после проверки UP полный прогон успешен. Отдельный screenshot-скрипт с 127.0.0.1 столкнулся с локальным CORS; проверка повторена на разрешённом localhost.
- Независимое ревью: закрыто замечание о порядке промежуточных WebSocket-снимков; новых блокирующих замечаний нет. Контраст text-muted на основных поверхностях 5.15–6.36:1.
- Публичная проверка HTTPS: QR декодирован в реальную hash-ссылку, новый участник зарегистрирован и подключён, 3 случайных бота заполнили места, завершены 3 раунда и открыта статистика. На 390px нет горизонтального переполнения и ошибок JS. Снимки и результат проверки сохранены вне Git. Физический проектор/камера телефона не проверялись.
- qrcode.react 4.2.0 генерирует SVG локально, jsqr 1.4.0 используется только в E2E. Предупреждение peer eslint/@eslint/js существовало до изменения, новые библиотеки не добавляют peer-конфликтов. Изменённые исходники отформатированы.

- Дополнительная граничная проверка воспроизвела переполнение новой монеты при 100000 на экране 320px. Для крупных сумм включено компактное начертание, адаптированы внутренние поля; regression E2E сначала упал на overflow, после исправления прошёл.
