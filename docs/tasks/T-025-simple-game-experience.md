## Контекст
Пользователь разрешил глобальный рефакторинг и самостоятельное принятие решений. Убираем лишние переходы, технический язык и тупики. React/Spring сохраняются: препятствия находятся в интерфейсе, а не в стеке.

## Acceptance criteria
- [x] На главной понятны правила и доступен учебный раунд без регистрации.
- [x] Вход по имени ведёт сразу в игры; приглашение сохраняет адрес партии.
- [x] Создание партии использует готовые настройки; дополнительные раскрываются отдельно.
- [x] Приглашение, подключение к командам, возврат участника и ожидание имеют явные действия.
- [x] Игровое действие видно прежде списка участников; отправка не зависает без обратной связи.
- [x] Результаты читаемы после обновления; подробности статистики доступны отдельно.
- [x] Доступность клавиатуры, мобильный экран, unit, build, lint и E2E проверены.
