## Контекст
Пользователь уточнил: глобальный рефакторинг охватывает возможности и backend, а не только UI. Разрешено самостоятельное принятие решений; требуется временный хостинг на текущем сервере. Старую облачную выкладку заменяем отдельным Compose-окружением.

## Решение
Сохраняем React/Spring. Добавляем реальные сольные партии против ботов, режим «Диктатор» для сравнения решений без права отказа, готовые сценарии, участие ведущего, серверную историю игр и реванш. Руководство объясняет действия игрока/ведущего и статистику. Аналитика показывает динамику счёта, потери от отказов и персональные показатели с фильтрами.

## Acceptance criteria
- [x] HTTPS URL на текущем сервере: frontend/API/WebSocket, отдельная постоянная БД, перезапуск контейнеров.
- [x] Любой игрок может создать свою игру; ведущий может играть; чужие игры защищены проверкой владельца.
- [x] Соло создаётся одним действием и проходит несколько реальных раундов с ботом.
- [x] Новый режим «Диктатор» начисляет очки автоматически, без фиктивного выбора ответа.
- [x] Мои игры и реванш используют серверные данные.
- [x] Руководство, готовые сценарии, графики динамики/потерь и фильтры доступны на мобильном.
- [x] Unit, backend check, E2E и HTTPS-проверка новых сценариев проходят.
