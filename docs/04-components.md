# 04. Компоненты интерфейса

| Компонент       | Ответственность                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------- |
| `AppShell`      | Основная навигация, skip-link, профиль, подтверждение выхода, фокус при переходе                      |
| `Parchment`     | Адаптивная светлая карточка без отвлекающих анимаций                                                  |
| `InkField`      | Поле с отдельной меткой, описанием, ошибкой и передаваемым ref                                        |
| `NumberStepper` | Числовое поле с прямым вводом и кнопками −/+; границы проверяются при уходе из поля                   |
| `RoleChoice`    | Выбор задачи: присоединиться или создать игру; объяснение роли ведущего                               |
| `SessionCard`   | Краткое описание игры и реальные свободные места                                                      |
| `SessionJoin`   | Общая логика подключения из списка и приглашения; выбор команды, возвращение участника, закрытая игра |
| `AddNpcPanel`   | Заполнение свободных мест ботами; максимум 100 за запрос; отдельный выбор готового бота               |
| `WaxSeal`       | Декоративный элемент технического style guide                                                         |

`Session.tsx` экспортирует панели предложения, решения, результатов и прерывания. Панели получают `RoundResponse` и сбрасываются по идентификатору раунда. `useGameCommand` предотвращает повторную отправку, ждёт изменения серверного состояния и предлагает обновить игру, если подтверждение не пришло за 10 секунд.

Общие классы `button`, `button-secondary`, `text-link`, `notice`, `choice-card`, `badge` заданы в `src/index.css`. Используйте семантические button/input/label/details. Уточняющие тексты поля должны быть описанием через `aria-describedby`, а не частью доступного имени.

В учебном режиме `Practice` объясняет один цикл предложения и ответа. Бот принимает от 30 монет и предлагает 40; это явно обозначенный пример, без запросов, записи результатов и влияния на настоящую игру.
