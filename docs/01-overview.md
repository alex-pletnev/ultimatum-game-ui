# 01. Обзор проекта

Ultimatum — многопользовательская игра о разделе общей суммы. Каждый участник предлагает долю другому игроку и принимает или отклоняет чужое предложение. Согласие приносит обеим сторонам их доли; отказ — ноль за сделку.

## Стек

React 19, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, STOMP.js. Backend — Spring Boot/PostgreSQL. Для проверок используются Vitest/Testing Library и Playwright. Дополнительных runtime-зависимостей для UX-рефакторинга T-025 не добавлено.

## Пользовательские маршруты

| Путь                           | Назначение                                                                             |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| `/`                            | Объяснение игры; авторизованных переводит в список игр                                 |
| `/practice`                    | Учебная сделка с локальным ботом, без сервера и регистрации                            |
| `/rules`                       | Короткие правила и объяснение ролей                                                    |
| `/register`                    | Вход по имени; PLAYER → `/lobby`, ADMIN → `/lobby/new`                                 |
| `/register?next=/session/{id}` | Сохраняет приглашение после входа; внешние адреса не принимаются                       |
| `/lobby`                       | Открытые игры, обновление списка, возврат к последней игре                             |
| `/lobby/new`                   | Готовые настройки: 4 игрока, 3 раунда, 100 монет; дополнительные раскрываются отдельно |
| `/session/{id}`                | Приглашение, ожидание, текущий ход или итог игры                                       |
| `/session/{id}/stats`          | Публичные результаты; анализ и сделки в дополнительном разделе                         |
| `/npc`                         | Создание ботов и настройка их поведения для ведущего                                   |
| `/_style-guide`                | Прямой технический маршрут, отсутствует в пользовательской навигации                   |

## Точки входа и состояние

`src/main.tsx` подключает QueryClient, STOMP и маршрутизатор. `AnimatedRoutes.tsx` содержит маршруты внутри `AppShell`; статистика, боты и style guide загружаются отдельно. В production используется HashRouter для GitHub Pages; ссылки приглашений строятся через `useHref`.

REST-данные — в TanStack Query, состояние форм — в React. JWT остаётся в существующем `auth-storage`; временный профиль нельзя восстановить после выхода. `recent-game` хранит только последнюю посещённую игру отдельно для каждого профиля.

WebSocket ускоряет обновления. REST восстанавливает детали, текущий раунд и счёт после перезагрузки или потери событий; запросы обновляются каждые 10 секунд на активном экране. Ошибка или отсутствие подтверждения команды показываются явно, автоматической повторной отправки нет.

## Визуальная система

Светлые поверхности, тёмно-зелёные действия, системный шрифт, размер основного текста 16px. Внешних шрифтов нет. Токены находятся в `src/styles/tokens.css`, общие элементы — в `src/index.css`. Основной ход расположен перед второстепенными сведениями; мобильная версия и клавиатура входят в E2E-проверки.
