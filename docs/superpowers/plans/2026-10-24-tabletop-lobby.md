# Комната настольной игры — план реализации

**Цель:** подключение аудитории по QR, заполнение ботами одним нажатием, выразительное оформление.
**Архитектура:** выделить существующее приглашение из Session в SessionInvite; локальный SVG QR + native dialog. Серверный endpoint заполняет места атомарно; клиент обновляет существующий query cache. Стили общих компонентов и токены сохраняют стек.
**Стек:** React 19, TypeScript, qrcode.react, Tailwind; Spring/Kotlin.
**Спецификация:** docs/tasks/T-027-tabletop-lobby.md.

## Ограничения и риски
- Сохранить ссылки HashRouter/GitHub Pages и регистрацию по приглашению.
- QR чёрный на белом, quiet zone 4 модуля, без декоративных перекрытий.
- Dialog: Escape, фокус и видимая кнопка закрытия, ограничение по высоте/ширине.
- Заполнение: только владелец, CREATED, текущая вместимость, правильные команды; без удаления людей.
- Мобильные экраны 390px и reduced motion; текст не зависит от внешних шрифтов.
