# Простой пользовательский путь — Implementation Plan

> Execution: superpowers:executing-plans. Пользователь поручил самостоятельно выбрать решения и довести работу до конца без дополнительных согласований.

**Goal:** новичок понимает правила и проходит первый раунд без регистрации, а совместная игра требует только имени и ссылки.
**Architecture:** сохранить React, TanStack Query, STOMP и Spring API. Упростить существующие страницы и общие компоненты; учебный режим локален и явно обозначен.
**Tech Stack:** React 19, TypeScript, Vite, Tailwind, Vitest, Playwright.
**Spec:** ../../tasks/T-025-simple-game-experience.md

## Ограничения

Русский интерфейс, доступность клавиатуры, 375px и desktop. Новых runtime-зависимостей не требуется. Существующие роли и данные сохраняются. Изменения в текущем чистом checkout по workflow проекта; публикация не является критерием завершения.

## Проверяемые риски

Приглашение после регистрации; пустые/недоступные партии; повторное подключение участника; несколько раундов подряд; пропущенное WebSocket-событие и обновление страницы.
